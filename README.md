# Simple AI Agent with Tools

This Python script demonstrates a basic AI agent that can use tools to respond to user queries. It simulates an LLM's decision-making process to select and use predefined tools like getting weather information or performing calculations, showcasing a fundamental agent architecture.

## Language

`python`

## How to Run

Save the code as `agent_demo.py` and run it from your terminal using `python agent_demo.py`. Interact by typing queries like 'What is the weather in Ankara?' or 'Calculate 5 * (10 + 2) = ?'.
